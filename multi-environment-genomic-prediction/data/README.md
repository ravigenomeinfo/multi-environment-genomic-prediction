# Data

**All data in `data/simulated/` are simulated. They do not represent any real maize panel or field trial.**

Generated by `R/01_generate_data.R` (seed set in `config.R`).

| File | Content |
|---|---|
| `genotypes_raw.csv` | Lines x SNPs, coded -1/1 (homozygous inbred lines), about 2% missing (`NA`) |
| `phenotypes_long.csv` | Simulated trait value (t/ha-like) for every line x environment cell (balanced design) |
| `env_covariates.csv` | Five measured environmental covariates per environment (only the first three influence the genetic correlations; the last two are noise) |
| `truth_genetic_values.csv` | Simulation ground truth: true genetic value of each line in each environment |
| `truth_env.csv` | Simulation ground truth: plot-level heritability and mean of each environment |
| `truth_lines.csv` | Simulation ground truth: subpopulation of each line |

The `truth_*` files exist only because the data are simulated. They are used to report
`r_tgv` (accuracy against true genetic values), to compare estimated and true
genetic correlations, and for figures. They are never used for model fitting.

`data/processed/` holds intermediate R objects and is git-ignored.

## Using your own data
Provide a genotype matrix (lines x SNPs, coded -1/0/1), a long-format phenotype table
(`line`, `env`, `y`) and an environment-by-covariate table, then remove the `truth_*`
dependencies (`r_tgv`, correlation-recovery figure) from scripts 02, 04, 05 and 06.
Real trials are usually unbalanced; the cross-validation code already handles missing
cells conceptually, but you must check model convergence on your data.
Only share data you are permitted to share publicly.
